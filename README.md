# Cosmo Star Game

**Cosmo Star Game** is a 2D browser platformer in which the player controls an astronaut exploring a space-themed world, overcoming obstacles, collecting points, and reaching the final star.

The main objective is to complete the level by reaching the star located at the end of the map.

## Features

* 2D platformer gameplay
* Space-themed environment
* Play as an astronaut
* Single and double jump mechanics
* Sprint using the **Shift** key
* Interactive bonus blocks
* Character growth after collecting a special power-up
* Point collection system
* Final star that completes the level
* Runs directly in any modern web browser

## Controls

| Key               | Action      |
| ----------------- | ----------- |
| **A**             | Move left   |
| **D**             | Move right  |
| **Space**         | Jump        |
| **Space (twice)** | Double jump |
| **Shift**         | Sprint      |

## Objective

Navigate through the level, avoid obstacles, collect as many points as possible, obtain power-ups from bonus blocks, and reach the final star to complete the game.

## Scoring System

Throughout the level, players can collect points to increase their score. Explore every part of the map to achieve the highest score before reaching the final star.

## Power-Ups

Some blocks contain special power-ups. Collecting one of these causes the astronaut to grow in size, adding a classic platformer mechanic to the gameplay.
